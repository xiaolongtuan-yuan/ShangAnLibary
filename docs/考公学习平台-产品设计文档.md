## 1. 产品背景与定位

### 1.1 用户痛点

1. **资料散落**：行测、申论、时政、真题散在网盘、微信、电脑文件夹里，没有统一管理。
2. **网盘预览体验差**：在线预览卡顿、不能做批注，想划重点只能下载到本地。
3. **资料找不到**：几十上百个 PDF，想找"哪篇资料讲过"某个知识点，只能一个个打开翻。
4. **分享没载体**：想把自己的资料分享给朋友一起备考，缺少一个"带账号、带权限、能各自做笔记"的地方。
5. **笔记易丢失**：本地 PDF 批注换设备就没了，且无法检索自己的笔记。

### 1.2 产品定位

- **不是网盘**：不以"存文件"为核心，而以"读资料、做笔记、找内容"为核心。
- **不是笔记软件**：笔记是附属能力，服务于"读 PDF"这个主场景。
- **是"资料 + 阅读 + 批注 + 检索"四位一体的云书房**：资料由站长统一维护，每个备考者有自己的私人批注空间。

### 1.3 目标用户

| 角色 | 说明 | 核心诉求 |
|---|---|---|
| 管理员（站长） | 产品拥有者，即你本人 | 快速上传/更新/分类资料，管理成员，看到使用情况 |
| 普通用户（备考朋友） | 被邀请注册的备考者 | 流畅阅读、随手批注、快速检索、进度不丢 |

### 1.4 设计原则

1. **管理员优先**：上传、建文件夹、删改是管理员特权，用户端零维护成本。
2. **隐私隔离**：批注、进度、收藏严格按账号隔离，互不可见（这是"每个账号隔离"的落点）。
3. **阅读沉浸**：阅读器无广告、无干扰，快捷键翻页，进度自动记忆。
4. **检索直达**：搜索不只给文件列表，而是定位到"第几页"，点击即达。

## 3. 核心功能详细设计

### 3.1 账号与访问控制

**邀请制注册（防滥用，私密站标配）**

```
管理员在后台生成邀请码（可设数量/有效期/一次性）
        ↓
朋友拿到邀请码 → 打开注册页 → 填写昵称/邮箱/密码 + 邀请码
        ↓
校验通过 → 创建账号 → 自动登录 → 进入学习工作台
```

- 邀请码特性：一次性使用、可设置有效期、可一键作废、可查看使用情况。
- 登录态：JWT（短期 access token + 长期 refresh token），支持"记住我"。
- 密码策略：至少 8 位含字母数字；bcrypt/argon2 加盐存储。
- 找回密码（轻量版）：V1.0 提供"管理员重置"，V1.1 增加邮箱验证码找回。
- 账号状态：正常 / 禁用（管理员可禁用，被禁用者无法登录，但数据保留）。
- 账号隔离实现：批注、书签、进度等所有"学习数据表"都带 `user_id`，所有查询强制带当前用户条件，后端做权限校验（不是前端隐藏）。

### 3.2 资料库管理（管理员专属）

**文件夹体系**

- 多级树形结构（建议 ≤ 3 层），示例：`行测 → 言语理解 → 2025 专项题集`
- 操作：新建、重命名、移动、排序、删除（删除时子级与文件一并处理或阻止并提示）。
- 推荐预置分类模板（首次初始化时可一键创建）：`行测 / 申论 / 面试 / 时政 / 真题套卷 / 其他`。

**上传与文件元数据**

- 拖拽多文件上传、文件夹内直传、同名文件提示"覆盖或新建"。
- 上传后自动提取：文件大小、页数、标题；管理员可补填：科目、阶段（基础/强化/冲刺）、年份、来源、标签（多个）。
- 上传限流：单文件 ≤ 200MB（可配置），支持断点续传（V1.1）。

**更新与版本**

- 管理员可"替换文件"：旧版本自动归档，保留版本历史（版本号、替换时间、备注），可回滚。
- 好处：资料修订时不用重新分享链接，朋友们的批注尽量兼容（页码位移时给出提示）。

**删除与回收站**

- 软删除 → 回收站（保留 30 天）→ 彻底删除；删除前二次确认，并提示"影响的所有用户批注将一并清除"。

### 3.3 在线 PDF 阅读器

基于 PDF.js 自研阅读器（不依赖网盘类组件），核心能力：

| 能力 | 说明 |
|---|---|
| 渲染 | 原文件矢量渲染，清晰度无损 |
| 目录大纲 | 读取 PDF 自带书签（Outline），点击跳页 |
| 页面导航 | 页码跳转、上下页、键盘 ←/→/PageUp/PageDown、空格翻页 |
| 视图 | 单页 / 连续滚动、缩放 50%~300%、适合宽度、全屏、双页（V1.1） |
| 进度记忆 | 自动记录"文件+页码+滚动位置"，重新打开直接续读 |
| 阅读器工具条 | 放大缩小、目录、批注开关、笔记面板、跳页、检索当前文档（V1.1） |

**性能要点**：大 PDF 分页懒加载 + 当前页/邻近页预渲染；打开 10MB PDF 目标 < 3 秒（首屏 < 1 秒）。

### 3.4 批注系统（★ 核心亮点）

> 说明：您提到的"在 pdf 上批准并永久记录"，我理解为「批注（划线/高亮/写笔记）并永久保存」。若您另有所指（如审批流程），请见 §10 确认。

**批注类型**

| 类型 | 交互 | 存储 |
|---|---|---|
| 高亮 / 下划线 / 波浪线 | 划词选择 → 弹出迷你工具条 → 选颜色即完成 | 坐标层数据 |
| 文字笔记（便签） | 选中文字或点页面任意位置 → 输入笔记 | 坐标层数据 |
| 书签 | 工具条点"加书签"，可命名 | 页码数据 |
| 重点标记 ★ | 一键标记，笔记面板可按★筛选 | 坐标层数据 |

**关键设计决策：坐标层叠加，不改原 PDF**

- 批注**不写入 PDF 文件本身**，而是存为结构化数据：`文件ID + 页码 + 类型 + 颜色 + 归一化坐标 + 文字内容`。
- 阅读器在渲染 PDF 之上叠加一层透明 canvas/SVG 绘制批注。
- 好处：
  1. 原文件纯净，永不损坏；
  2. 天然支持**多账号隔离**（批注表带 `user_id`，谁的数据就是谁的）；
  3. 支持版本管理（换文件不影响批注结构）；
  4. 批注可导出、可迁移、可统计。
- 坐标统一以"PDF 原始页面坐标系（0~1 归一化）"存储，前端按当前缩放比例换算渲染 → 缩放、全屏都不会错位。

**永久记录与数据安全**

- 批注操作即时落库（乐观保存 + 防抖），断网重连后自动补存。
- 批注列表按文件聚合，支持按页/按类型筛选、按颜色图例查看。
- 笔记导出：单文件或全库导出为 Markdown / PDF（用于打印背诵版）。

### 3.5 检索系统

**检索范围（可多选过滤）**

1. 文件名 / 文件夹名 / 标签 / 科目
2. **PDF 全文内容**（核心能力）
3. 自己的批注内容（笔记文字、高亮文字）

**全文检索实现思路**

- 上传/替换 PDF 时，后台异步任务提取文本（PDF.js 或 pdftotext；扫描件走 OCR 为 V2 能力），按页切片后建立中文分词索引（PostgreSQL zhparser / pg_jieba，或 Meilisearch / Elasticsearch + IK）。
- 索引状态可见：管理员上传后能看到"已索引 / 索引中 / 失败重试"。

**结果体验（检索直达）**

- 结果按"文件分组"，显示命中片段（关键词高亮）+ 页码。
- 点击结果 → 打开该 PDF 并**自动跳转到对应页**，同时定位高亮命中词。
- 支持高级筛选：按科目/文件夹/批注类型；支持检索历史与热门检索词（管理员可看，帮助了解朋友们的备考重点）。

**性能目标**：普通检索 < 1 秒；检索索引对用户完全透明。

### 3.6 学习辅助（V1.1+ 渐进增强）

- 首页"继续阅读"：最近在读的 5 个文件一键续读。
- 我的收藏：收藏文件/文件夹，形成个人书单。
- 错题标记：批注类型加"错题"，可单独聚合导出错题本。
- 阅读统计（V2）：阅读页数/时长、连续学习天数，激励坚持。
- 移动端适配（V2）：手机端阅读体验优化。

- 结果分组：`文件名命中` / `内容命中（按文件折叠，展示命中片段+页码）` / `我的笔记命中`。

### 4.6 管理后台

- **用户管理**：成员列表（昵称/邮箱/注册时间/最近登录）、禁用/启用、重置密码、查看某用户的阅读量（不看他批注内容，保护隐私）。
- **邀请码管理**：生成/作废/查看使用情况。
- **系统设置**：站点名称、上传大小上限、允许注册开关、备份入口。

### 4.7 个人中心

- 资料编辑（昵称/头像/密码修改）、主题（浅色/深色）、数据导出（我的笔记/书签）、账号注销。

## 5. 数据模型设计（核心实体）

```
users               用户表
├─ id, username, email, password_hash, role(admin/user),
│  status(normal/disabled), invite_code_id, created_at

folders             文件夹表
├─ id, name, parent_id(自引用), sort, created_by

documents           资料文件表（全站共享，无 user 归属）
├─ id, folder_id, title, subject, stage, year, source,
│  tags[], file_key(存储路径), file_size, page_count,
│  text_extract_status(pending/done/failed), version, deleted_at

document_versions   文件版本表
├─ id, document_id, version_no, file_key, file_hash, note, created_at

annotations         批注表（★账号隔离的根基）
├─ id, user_id, document_id, page, type(highlight/underline/
│  wave/note/star), color, rect(归一化坐标JSON), content,
│  created_at, updated_at

bookmarks           书签表
├─ id, user_id, document_id, page, label, created_at

reading_progress    阅读进度表
├─ id, user_id, document_id, page, scroll_y, updated_at

invite_codes        邀请码表
├─ id, code, max_uses, used_count, expires_at, revoked, created_by

全文索引            由 PostgreSQL FTS 或 Meilisearch/ES 管理，
                   （不需要手工建表，随文本提取任务写入）
```

**关键约束与索引**

1. `annotations / bookmarks / reading_progress` 均含 `user_id`，且所有业务查询强制 `WHERE user_id = 当前登录用户` → 账号隔离由后端兜底。
2. `documents` 不挂 user → 资料库为全站统一视图。
3. 高频索引：`annotations(user_id, document_id)`、`documents(folder_id)`、`reading_progress(user_id)`。
4. 批注坐标用归一化 JSON 存储（`{x1,y1,x2,y2}`，0~1），渲染时乘当前缩放系数。

## 6. 技术方案

### 6.1 总体架构

```
浏览器（Vue3 SPA）
   │ HTTPS
   ▼
Nginx（反向代理 + 静态资源 + 证书终结）
   ├── /api/* ──► 后端服务（REST API + 认证）
   │                  ├── PostgreSQL（业务数据 + 全文索引）
   │                  ├── 文件存储（MinIO/本地磁盘卷/云OSS）
   │                  └── 异步任务队列（PDF文本提取/索引，BullMQ/Celery）
   └── 静态资源（前端构建产物）
```

### 6.2 推荐技术栈（含备选）

| 层 | 推荐选型 | 备选 | 理由 |
|---|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite | React 18 | 上手快、生态成熟，阅读器用 PDF.js |
| UI 组件 | Element Plus | Ant Design Vue | 管理后台类界面开箱即用 |
| 阅读器 | PDF.js（Mozilla 官方） | pdfium / 自研 | 矢量渲染、文本层提取一条龙 |
| 后端 | **Python FastAPI + SQLAlchemy 2.0 + Alembic** | Django REST Framework / Flask | 按您的偏好选 Python；FastAPI 异步高性能、自带 OpenAPI 文档 |
| 数据库 | PostgreSQL 16 | MySQL 8 | 中文全文检索（pg_jieba/zhparser）更优 |
| 全文检索 | **PostgreSQL + pg_trgm**（起步） | pg_jieba 分词 / Meilisearch（体验不足再升级） | 零额外服务、中文子串匹配够用；检索服务接口不变、可平滑升级 |
| 文件存储 | 本地磁盘卷 + 定时备份到 OSS | MinIO 自托管 / 阿里云OSS | 几十人规模本地够用，OSS 兜底备份 |
| 认证 | JWT（access + refresh） | session + Redis | 无状态、多端友好 |
| 部署 | **Docker Compose + Nginx（公网 IP 直连）** | Cloudflare Tunnel（免费 HTTPS） | 无需域名与备案，一条命令起服务 |

### 6.3 关键实现要点

1. **PDF 文本提取管道**：上传后进队列 → 逐页提取 → 按页入库/入索引 → 更新索引状态；失败自动重试 3 次。
2. **批注坐标渲染**：存储 0~1 归一化坐标，前端按 `当前缩放 × 页面实际尺寸` 换算，保证缩放/全屏不错位；批注层与 PDF 层分离渲染。
3. **大文件性能**：PDF.js `getDocument` + 按需加载页纹理，虚拟滚动；分片上传（V1.1）。
4. **并发安全**：批量上传任务化，避免大文件阻塞接口；文件替换期间锁定该文件索引任务。

## 7. 安全与合规

1. **注册防滥用**：仅邀请码注册；邀请码一次性、可过期、可作废；登录接口限流（防爆破）。
2. **越权防护（重点）**：所有文件与学习数据接口后端校验登录态 + 数据归属；用户 A 请求用户 B 的批注必须返回 403；文件下载用**预签名短时效 URL**，不暴露存储路径。
3. **数据安全**：密码 bcrypt/argon2；JWT 密钥环境变量管理；全站 HTTPS。
4. **隐私**：批注默认仅本人可见（含对管理员）；后台"用户管理"只展示学习量统计，不展示批注内容。
5. **合规**：资料版权自查（仅上传有权限分发的资料）；若对外公开需用户协议 + 隐私政策。
6. **容灾**：数据库每日备份 + 文件增量备份；提供一键恢复脚本。

## 9. V1.0 验收标准
